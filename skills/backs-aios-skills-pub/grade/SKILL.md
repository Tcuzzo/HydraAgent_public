# Grade Command

Load and execute the complete [grading-verification play](../../plays/grading-verification.md)
on the current diff or the user's supplied scope. In a copied portable install, load
`~/.local/share/backs-aios/current/plays/grading-verification.md` instead. A green test
is a claim; keep attacking until the play's proof bar is met or the defect is loud.
