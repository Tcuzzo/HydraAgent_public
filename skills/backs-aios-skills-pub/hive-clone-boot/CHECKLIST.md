# Public deployment checklist

No host is certified by this distributed checklist. Record current evidence for:

- Source revision and installed package identity.
- Configured model transport, optional local SDK dependencies and actual devices.
- Ordinary CLI/tool execution under the existing authorization policy.
- Fresh source keys and versioned embedding identity.
- Independent review routes, or an explicit degraded result.
- Bounded queues, reset times, cancellation and recoverable state.
- Public/private separation and upstream attribution.
- Deployed behavior when deployment is part of the authorized task.

Use observed statuses with timestamps. Do not carry forward old GREEN labels.
