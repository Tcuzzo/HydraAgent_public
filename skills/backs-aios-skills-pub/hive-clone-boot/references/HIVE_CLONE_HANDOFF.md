# Public hive handoff

This is a generic public edition. Historical private deployment notes, machine
identifiers, account paths and operational receipts are not distribution content.
Private canon and essence belong in an explicitly configured local overlay.

Load the invariant floor and compile the current task context. Verify the selected
checkout, configured endpoints and available tools. Assign bounded work to the
roles in `../roster.yaml`; their descriptions are guidance, not proof of a running
service. Use independent configured families for consequential review, with actual
route identities and frozen evidence. Normal single-model work can continue when
independent review is unavailable, with that limitation stated.

Record the owner, source revision, observed result and remaining uncertainty.
Preserve failed work and checkpoints before changing routes. Rate limits, exhausted
budget, retired models, transport failures and unknown action outcomes are distinct
states. Honor reset times, avoid duplicate actions and never invent unlimited backup
providers. Validate installation, execution and deployment separately.
