# Contributor attribution

Hydra is Cuzzo's (Tcuzzo's) project, developed with BACKS AIOS. Credit the human
contributor for authorship and BACKS AIOS as the development platform.

- Codex/OpenAI, Claude/Anthropic, other models, coding assistants, and generators
  receive tool credit only. Do not put them in author or co-author fields,
  `Co-Authored-By:` trailers, or copyright notices.
- Record only tools actually used, in plain provenance text or a `Tool-Used:`
  trailer. Do not fabricate model names, versions, or contribution claims.
- Keep legitimate human contributor credits, including existing Matt Pocock skill
  scaffold credits. Preserve upstream skill authors, source links, copyright
  notices, and license terms; tool-credit rules do not erase borrowed-source credit.
- Before opening a pull request, inspect its new commit messages and description
  for accidental model co-author footers. Correct new unpublished messages when
  needed. Do not rewrite published history as part of an ordinary pull request.

See [PROVENANCE.md](PROVENANCE.md#project-and-tool-credit) for the credit policy.
